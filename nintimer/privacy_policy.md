Nintimer（以下「本ソフトウェア」）を提供する `poola-vii`（日本在住の個人。以下「当方」）は、本ソフトウェアの利用にあたって次のとおり取り扱います。

## 要点

- **本ソフトウェアは、インターネットに通信しません。**
- **当方は、利用者の情報を収集しません。**
- **本ソフトウェアが作るファイルは、すべて利用者の PC の中だけに置かれます。**

## 1. 収集しない情報

本ソフトウェアは、次のいずれも行いません。

- 利用状況、操作履歴、動作記録の送信（テレメトリ、アナリティクス）
- 利用者や PC を識別する情報の取得・送信
- 広告の表示、広告のための情報の取得
- 更新の確認を含む、あらゆるサーバーへの接続

本ソフトウェアには、外部と通信する機能そのものがありません。アプリの中の「利用条件・ライセンス・入手先」の窓も、外部のページを開きません。

## 2. PC の中で扱う情報

本ソフトウェアは、動作のために次の情報を **PC の中だけで** 扱います。**外部へ送信しません。** 発表の中身（スライド、ほかのアプリの画面や文字）は読みません。ほかのアプリの窓について扱うのは、窓とプロセスの識別番号と、見えているか・最小化されているかなどの状態だけです。

| 扱う情報 | 何のため | どこに置くか |
|:---|:---|:---|
| 計時の状態（計時中・一時停止中の値） | タイマーを表示するため | メモリ上のみ。終了すると消えます |
| 利用者が決めた設定（指定方法、持ち時間、開始時刻と終了時刻、表示の大きさ、割合バーの位置と向き、表示の言語、タイマーの位置） | 次に起動したときに引き継ぐため | 下記 §3 の設定ファイル |
| タイマーの位置を自動で直したときの記録（直す前と後の位置、そのときのディスプレイの位置と大きさ） | うまく動かないときに調べるため | 下記 §3 のログファイル |
| 直前に使っていたアプリの窓の識別番号（窓とプロセスの番号。最大8件） | タイマーのメニューや設定画面などを使い終えたあと、キー入力を受ける窓をスライドショーなどへ戻すため | メモリ上のみ。終了すると消えます |
| キー入力を受ける窓を戻したときの記録（戻した先と、そのあとキー入力を受ける窓になった窓の識別番号、戻せたかどうか） | うまく動かないときに調べるため | 下記 §3 のログファイル |

## 3. 設定ファイルとログファイル

| | |
|---|---|
| 置き場所 | `%APPDATA%\nintimer\`（通常は `C:\Users\<ユーザー名>\AppData\Roaming\nintimer\`） |
| 設定ファイル | `config.json`。テキスト（JSON）で、メモ帳などで中身を読めます |
| ログファイル | `nintimer.log`。次のときだけ書きます: ディスプレイの構成が変わって、タイマーが画面の外に出そうになり、位置を自動で直したとき。タイマーのメニューや設定画面などを使い終えて、キー入力を受ける窓を戻したとき（戻せなかったときを含む）。キー入力を戻すための、前面の窓が変わった知らせを受ける準備ができなかったとき（起動のとき）。トレイのアイコンを出せなかったとき。窓の題名や中身は書きません。256KB を超えると消して書き直します |

Microsoft Store 版は、上の場所に `nintimer` のフォルダーがない PC では、Windows がアプリ専用の場所（`%LOCALAPPDATA%\Packages\` の下）へ振り替えます。この場合、Store 版をアンインストールすると設定とログも消えます。

### 削除のしかた

本ソフトウェアをやめるときは、次のようにします。

- **Store 版**: Windows の設定からアンインストールします。上の `%APPDATA%\nintimer` がある場合は、**アンインストールしても残ります**。手で削除してください。
- **ポータブル版**: `nintimer.exe` を削除し、`%APPDATA%\nintimer` のフォルダーを削除します。
- 本ソフトウェアは、レジストリに書き込みません。
