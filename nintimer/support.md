Nintimer 1.0.1（公開β）時点の内容です。

## 問い合わせ先

窓口は、poola-vii の作るソフト全体で共通の <https://github.com/poola-vii/support> です。**Nintimer のことだと分かるように**書いてください。

| 用件 | 送り方 |
|:---|:---|
| 不具合の報告、使い方の質問、要望 | リポジトリの **Issues** から、用意したフォームを選んで投稿してください。**投稿には GitHub のアカウントが要ります**（無料で作れます） |
| 脆弱性の報告 | リポジトリの **Security** タブから **Private Vulnerability Reporting** で送ってください。**公開の Issue には書かないでください** |
| Microsoft Store のレビューに書いた内容 | 気づいたら公開で返信し、この窓口へご案内します。Store のレビューでは個別のやり取りができないためです |

**日本語と英語で受け付けます。** 英語でのお問い合わせは、返事が日本語より遅れることがあります。

### 書かないでいただきたいこと

公開の Issue は誰でも読めます。次を書かないでください。

- **個人情報** — 氏名、住所、電話番号、メールアドレス、勤務先など
- **発表の中身** — スライドの題名や文字、発表の場所や相手が分かること。画面の写しを貼るときは、スライドの部分を隠してください
- **認証情報** — パスワード、トークン、APIキーなど
- **まだ公表されていない脆弱性の情報** — Private Vulnerability Reporting をお使いください

投稿された内容がこれに当たると判断したときは、こちらで編集または削除することがあります。

### 知らせていただきたいこと

次の3つがあると、たいていのことは調べられます。

- **何をしたら、何が起きたか。** できれば手順を順番に。使っていたプレゼンソフトの名前と、全画面のスライドショーの最中だったかも。
- **Nintimer の版。** トレイかタイマーを右クリックしたときのメニューの、いちばん上に出ます（例: `Nintimer v1.0.1`）。Store 版かポータブル版かも。
- **Windows の版。** 「設定 > システム > バージョン情報」の「エディション」「バージョン」「OS ビルド」。

あわせて、ディスプレイの数と、それぞれの解像度と表示倍率（「設定 > システム > ディスプレイ」）も書いていただけると助かります。

## ログの採り方

Nintimer がファイルに書く記録は、**タイマーの位置を自動で直したとき**（ディスプレイを外したり、解像度を変えたりして、タイマーが画面の外に出そうになったとき）と、**タイマーのメニューや設定画面などを使い終えて、キー入力を受ける窓をスライドショーなどへ戻したとき**の記録です。ほかに、起動のときにトレイのアイコンを出せなかったときと、キー入力を戻す準備（前面の窓が変わった知らせを受ける準備）ができなかったときにも1行書きます。計時の様子は記録しません。

タイマーが見えなくなった、思わぬ場所に動いた、メニューや設定画面を使ったあとにスライドが進まなくなった、というときは、次のファイルを添えてください。

1. エクスプローラーのアドレス欄に `%APPDATA%\nintimer` と入れて開きます。
2. `nintimer.log` をメモ帳で開き、中身を問い合わせの入力欄に貼り付けます。中身は日時と、位置とディスプレイの座標と大きさ、キー入力を戻した先の窓の識別番号（番号だけで、窓の題名や中身は入りません）と戻せたかどうかです。
3. ファイルが無ければ、上のどれも起きていないという意味です。そのこと自体が手がかりになります。

**Store 版**で、上の場所に `nintimer` のフォルダーが無いときは、Windows が振り替えた場所にあります。エクスプローラーのアドレス欄に `%LOCALAPPDATA%\Packages` と入れて開き、名前に `Nintimer` を含むフォルダーの中の `LocalCache\Roaming\nintimer` を見てください。

設定ファイル（`config.json`）を添えていただく必要は、ふつうはありません。必要になったときはこちらからお願いします。

## サポート範囲

### 対応すること

- 公開βとして出している最新の版で起きる不具合の調査
- 使い方の質問への回答
- 既知の問題の更新
- 直すと決めたものの修正（次の版で入れます）

### 対応しないこと

これらは**できないこと**であって、頂いた報告を軽く見るという意味ではありません。

- **古い版のサポート。** 最新の版でも起きるか確かめてからお知らせください。
- **対応しないと決めている環境。** ARM の PC、32 ビットの Windows、Windows 以外の OS。
- **既知の問題に「仕様として、そうしていること」として書いてあること。** そうする理由があって選んでいます。ただし、ご意見はうかがいます。
- **特定のプレゼンソフトとの連携。** Nintimer は画面の最前面に重なるだけで、プレゼンソフトとはつながりません。
- **電話や対面での対応。**

### お約束できないこと

**公開βは、個人が余暇に作って無償で配っているものです。**

- **返信の速さをお約束できません。** 数日から数週間かかることがあります。
- **すべての報告に対応するとはお約束できません。** 直さないと決めることがあります。その場合は理由をお返しします。
- **公開を続けることをお約束できません。** 配布をやめることがあります。そのときは配布元でお知らせします。
- **公開βの間、予告なく挙動が変わることがあります。** 大きく変わるときは[変更履歴](CHANGELOG.md)に書きます。

詳しくは[利用条件](terms.md)をご覧ください。
