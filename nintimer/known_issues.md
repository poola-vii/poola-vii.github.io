Nintimer 1.0.1（公開β）時点で分かっている問題と、動作を確かめた環境です。

気づいたことがあれば、[問い合わせ窓口](support.md)へお知らせください。分かったことは、このページに足していきます。

## 仕様として、そうしていること

直す予定のない、意図した挙動です。

### 一時停止は、続きから再開しません

一時停止すると、止めた瞬間の値がグレーで残ります。そこから「開始」を選ぶと、**続きからではなく 0 から測り直します**（持ち時間なら最初の時間から、カウントアップなら `00:00` から）。英語の画面では、一時停止を「Stop」、一時停止中の開始を「Start over」と表示します。

始まらなかった発表を測り直すため、終わった発表の時間を読むための操作です。続きから測る操作はありません。

### 設定の「OK」を押すと、計時は最初からになります

計時中や一時停止中に設定画面で「OK」を押すと、そのときの計時はなくなり、新しい設定で待機中に戻ります（終了時刻で指定しているときは、新しい時間枠がそのまま始まります）。**表示の言語を変えたときも同じです。** 言語や表示の設定は、発表の前に決めてください。

### タイマーは聴衆にも見えます

タイマーは、投影する画面そのものの隅に重ねて出します。小さく半透明にしていますが、聴衆にも見えます。隠したいときは、タスクトレイのアイコンを右クリックして「オーバーレイを隠す」を選びます（計時は続きます）。

### 表示の言語は日本語と英語の2つです

Windows の表示言語が日本語なら日本語、それ以外は英語で出ます。設定画面のいちばん下の「言語 / Language」で、日本語か英語に決めることもできます。ほかの言語にはできません。メッセージの窓のボタンのように Windows が描く部分は、Windows の言語のまま出ます。

### 音を出しません。通信しません。更新を知らせません

時間が来ても音は鳴りません。アプリからインターネットへ接続しません。新しい版が出ても、アプリは何も言いません。Store 版は Store が更新します。ポータブル版は配布元（https://github.com/poola-vii/Nintimer-releases ）を見てください。

### 計時の状態は保存しません

Nintimer を終了したり、PC を再起動したりすると、計時はなくなり、次の起動は待機中から始まります。設定とタイマーの位置は残ります。

## 気をつけていただきたいこと

### Store 版は、Store が更新すると終了することがあります

Microsoft Store が Nintimer を更新すると、動いていた Nintimer が終了することがあります。発表の最中に起きると、タイマーが消えます。

Store 版のパッケージは、使っている間は更新を延ばすように宣言しています。ただし、この宣言は Windows 11 24H2 より前の Windows では効きません。また、Nintimer で実際に効くことは、まだ確かめていません。確かめるまでは、この項目を外しません。

発表の最中に終了させないための回避策は2つあります。どちらかを選んでください。

- **発表の日の前に、Microsoft Store のアプリの更新を一時停止する。** Microsoft Store の「設定」で「アプリ更新」のスイッチを切ると、「更新の一時停止」の窓が出ます。「一時停止の期間」を 1 週間・2 週・3 週・4 週・5 週から選び、「確認」を押します（Microsoft の案内「Microsoft Store でアプリやゲームの更新プログラムを入手する」）。発表が終わったら戻してください。
- **ポータブル版を使う。** ポータブル版は、利用者がファイルを置き換えるまで変わりません。

### Store 版とポータブル版を同じ PC に入れたとき

- **動くのは、先に起動したほうの1つだけです。** あとから起動したほうは、何も言わずに終了します。
- **設定は、PC によって共有されたり、分かれたりします。** `%APPDATA%\nintimer` のフォルダーがある PC（ポータブル版を先に使っていた PC）では、2つの版は同じ設定を使います。無い PC では、Store 版の設定は Store 版専用の場所に作られ、ポータブル版とは別になります。Store 版をアンインストールすると、その専用の場所の設定は消えます。

### ポータブル版は、初回の起動で警告が出ます

署名を付けていないためです。「詳細情報」→「実行」で起動します。Smart App Control がオンの PC では起動できません。Store 版をお使いください。

### 一部の全画面アプリより前には出せません

DirectX の排他的なフルスクリーンで動くアプリ（一部のゲームや動画のアプリ）の上には、タイマーを出せません。Windows の仕組みによるものです。通常の全画面のスライドショーの上には出ます。

### 「利用条件・ライセンス・入手先」の窓は、タイマーの下に入ります

タイマーはいつも最前面にあるので、この窓と重なった部分はタイマーが覆います。読むときは窓を動かしてください。

## 動作を確かめた環境

作者の手元の PC（Windows 11 Home、64 ビット、x64）で、ポータブル版と Store 版を LibreOffice Impress の全画面のスライドショーと一緒に使って確かめています。ディスプレイは1台で、表示倍率は 100%・150%・200% です。Store 版は、公開の前に開発者モードで入れて、全画面のスライドショーの上での表示・起動・設定の置き場所・二重起動の防止を確かめています。英語の表示は、言語の設定を English にした状態と、表示言語が英語の Windows のユーザーで確かめています（英語の Windows では、全画面のスライドショーとの組み合わせは確かめていません）。

次の表は、それ以外の環境の状況です。「未検証」は、まだ確かめていないという意味です。

| 環境 | 状況 |
|:---|:---|
| Windows 10 22H2 | 未検証 |
| PowerPoint のスライドショー | 未検証（同じ仕組みで最前面に出ると見込んでいますが、確かめていません） |
| ディスプレイごとに違う表示倍率（例: ノート PC 150% とプロジェクター 100%） | 未検証 |
| ARM の PC、32 ビットの Windows | 対応しません |
| Microsoft Store から入れた状態 | 未検証（公開のあとに確かめます）。Store による自動更新も未検証 |
