[English](index.en.md)

**発表中に、投影する画面の隅で残り時間を教えてくれるタイマーです。**

発表者向けの画面（PowerPoint の発表者ビューなど）が使えない会場でも、スライドと同じ画面の隅に、小さな半透明のタイマーを最前面で重ねます。手元の画面とスクリーンのあいだで目を往復させずに、残り時間が分かります。

> **いまは無料の公開βとして配っています。** 気づいたことがあれば、[問い合わせ窓口](support.md)からお知らせください。分かっている問題は[既知の問題](known_issues.md)にまとめています。

## できること

- **3つの測り方** — 持ち時間（例: 20分）、開始時刻と終了時刻（例: 13:00〜13:30）、カウントアップ。
- **色と割合バーで分かる** — 待機中と一時停止中はグレー、計時中は白、時間を過ぎると赤で `+03:05` のように超過時間を出します。残りの割合をバーで示します。
- **発表の邪魔をしない** — キーボードを奪わないので、スライド送りの操作はそのままプレゼンソフトに届きます。音は出しません。
- **全画面のスライドショーの最中でも操作できる** — タイマーを右クリックすれば、開始・一時停止・設定ができます。ドラッグで動かせます。
- **やり直せる** — 始まらなかった発表は、右クリック → 一時停止 → 開始 で 0 から測り直せます。
- **日本語と英語** — Windows の表示言語に合わせて出ます。設定画面で選ぶこともできます。

## 動作条件

| | |
|---|---|
| OS | Windows 11（64 ビット、x64）で動作を確かめています。ARM と 32 ビットの Windows には対応しません |
| .NET | **不要**です。実行に必要なものは同梱しています |
| プレゼンソフト | LibreOffice Impress の全画面のスライドショーで動作を確かめています |
| 表示倍率 | 100%・150%・200% で動作を確かめています |

ほかの環境の状況は[既知の問題](known_issues.md)の表にあります。

## 最初に使うとき

1. `nintimer.exe` を実行します（Store 版はスタートメニューから起動します）。
2. 画面の右上に小さなタイマーが出ます。タスクトレイにもアイコンが出ます。
3. タイマーかトレイのアイコンを右クリックして「設定...」を選び、持ち時間などを決めて「OK」を押します。
4. 発表を始めるときに、タイマーをダブルクリックするか、右クリックして「開始」を選びます（開始時刻と終了時刻で指定したときは、「OK」を押したときから時間枠が有効になるので、開始の操作は要りません）。
5. 終わったら、右クリックして「一時停止」を選ぶと、止めた値が残ります。

**表示の言語**: Windows の表示言語が日本語なら日本語、それ以外は英語で出ます。設定画面のいちばん下の「言語 / Language」で決めることもできます。言語を変えて「OK」を押すと、計時は最初からになるので、発表の前に決めてください。

**最初は自動で起動しません。** 発表のときに起動してください。

設定は `%APPDATA%\nintimer\config.json` に保存されます。ポータブル版をやめるときは、`nintimer.exe` とこのフォルダーを削除してください。
