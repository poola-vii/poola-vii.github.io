[English](index.en.md)

**発表中に、時間のことで気を取られないようにするタイマーです。**

投影する画面の隅に小さく重なるので、スクリーンから目を離さずに時間が分かります。時間が来ても音も点滅も出さず、スライド送りのキーにも触れません。開始時刻と終了時刻を入れておけば、開始を押す必要もありません。

発表者向けの画面（PowerPoint の発表者ビューなど）が使えない会場でも使えます。

> **準備中です。まだ配っていません。** Microsoft Store の審査を待っている段階です。公開βを始めたら、この表示を外します。それまでは、下の Microsoft Store のリンクとポータブル版の入手先は開けません。

## できること

- **発表の邪魔をしない** — 小さく半透明で、時間が来ても音も点滅も出しません。出すのは時間と色と細いバーだけで、「待機中」のような文字も出しません。
- **時刻で決まった枠なら、開始を押さなくていい** — 「13:00〜13:30」のように、設定画面で開始時刻と終了時刻を入れて「OK」を押しておけば、13:00 になると自分で計り始めます。Nintimer を起動し直しても、日付が変わっても、その日の 13:00 に計り始めます。数字は現在時刻で、残りは細いバーが示します。前の日や休憩中に入れておけば、発表の始めに開始を押し忘れる心配がありません。
- **スライド送りのキーに触れない** — キーボードの入力を奪わないので、スライド送りの操作はそのままプレゼンソフトに届きます。タイマーはマウスだけで操作できます。
- **全画面のスライドショーの最中でも操作できる** — タイマーを右クリックすれば、開始・一時停止・設定ができます。邪魔になったらドラッグで動かせます。
- **予定どおりにいかない発表にも** — 持ち時間とカウントアップでは、トラブルで止めたいときは右クリック → 一時停止、続けるときは「再開」で、止めた値から測り続けます（止めていたあいだは数えません）。始まらなかった発表は、一時停止 → 「最初から開始」で 0 から測り直せます。終わったら一時停止すると、止めた値が残ります。
- **3つの測り方** — 持ち時間（例: 20分）、開始時刻と終了時刻（例: 13:00〜13:30）、カウントアップ。時間を過ぎると赤に変わり、持ち時間では `+03:05` のように超過時間を数えます。
- **日本語と英語** — Windows の表示言語に合わせて出ます。設定画面で選ぶこともできます。

## 最初に使うとき

1. `nintimer.exe` を実行します（Store 版はスタートメニューから起動します）。
2. 画面の右上に小さなタイマーが出ます。タスクトレイにもアイコンが出ます。
3. タイマーかトレイのアイコンを右クリックして「設定...」を選び、持ち時間などを決めて「OK」を押します。
4. 発表を始めるときに、タイマーをダブルクリックするか、右クリックして「開始」を選びます（開始時刻と終了時刻で指定したときは、「OK」を押しておけば、起動し直しても時間枠が有効なので、開始の操作は要りません）。
5. 止めるときは、右クリックして「一時停止」を選ぶと、止めた値が残ります。続けるときは「再開」、0 から測り直すときは「最初から開始」を選びます（持ち時間とカウントアップのとき）。

**表示の言語**: Windows の表示言語が日本語なら日本語、それ以外は英語で出ます。設定画面のいちばん下の「言語 / Language」で決めることもできます。言語を変えて「OK」を押すと、計時は最初からになるので、発表の前に決めてください。

**最初は自動で起動しません。** 発表のときに起動してください。

設定は `%APPDATA%\nintimer\config.json` に保存されます。ポータブル版をやめるときは、`nintimer.exe` とこのフォルダーを削除してください。
