HamonPlayer 1.0.6（公開β）時点の内容です。

## 問い合わせ先

窓口は、poola-vii の作るソフト全体で共通の2つです。**おすすめは1つ目の <https://github.com/poola-vii/support> です。** どちらの窓口でも、**HamonPlayer のことだと分かるように**書いてください。

| 窓口 | 向いていること |
|:---|:---|
| **1. <https://github.com/poola-vii/support>（おすすめ）** | 用件ごとのフォームがあり、知らせていただきたいことを漏れなく書けます。ほかの人の報告や、こちらの返答も読めます |
| 2. メール（`poola.vii.support@gmail.com`） | GitHub のアカウントを持っていない方、作りたくない方向けです |

| 用件 | 送り方 |
|:---|:---|
| 不具合の報告、使い方の質問、要望 | 1つ目のリポジトリの **Issues** から、用意したフォームを選んで投稿してください。**投稿には GitHub のアカウントが要ります**（無料で作れます）。アカウントがなければ、メールでも受け付けます |
| 脆弱性の報告 | 1つ目のリポジトリの **Security** タブから **Private Vulnerability Reporting** で送ってください。**公開の Issue には書かないでください**。GitHub のアカウントがなければ、メールで送ってください |
| Microsoft Store のレビューに書いた内容 | 気づいたら公開で返信し、この窓口へご案内します。Store のレビューでは個別のやり取りができないためです |

メールで頂いた内容は公開しません。調べた結果、ほかの利用者にも関わることが分かったときは、送ってくださった方が分からない形にして、1つ目のリポジトリや[既知の問題](known_issues.md)に書くことがあります。

**日本語と英語で受け付けます。** 英語でのお問い合わせは、返事が日本語より遅れることがあります。

### 書かないでいただきたいこと

公開の Issue は誰でも読めます。次を書かないでください。メールでも、認証情報は送らないでください。

- **個人情報** — 氏名、住所、電話番号、メールアドレス、勤務先など
- **読んで確かめていないログ** — ログには曲のフォルダの場所が入り、Windows のユーザー名が含まれることがあります。[ログ採取方法](log_collection.md)のとおり、中身を読んで、渡したくないものを消してから貼ってください
- **曲のファイルそのもの** — 曲のファイルは添えないでください。画面の写しを貼るときは、出したくない曲名やフォルダの名前を隠してください
- **認証情報** — パスワード、トークン、APIキーなど
- **まだ公表されていない脆弱性の情報** — Private Vulnerability Reporting をお使いください

投稿された内容がこれに当たると判断したときは、こちらで編集または削除することがあります。

### 知らせていただきたいこと

次の3つがあると、たいていのことは調べられます。

- **何をしたら、何が起きたか。** できれば手順を順番に。起きた時刻も。
- **HamonPlayer の版。** アイコンの右クリックのメニューの「ヘルプ」の中の、いちばん下の行に出ます（例: `HamonPlayer 1.0.6`）。Store 版か setup.exe 版かも。
- **Windows の版。** 「設定 > システム > バージョン情報」の「エディション」「バージョン」「OS ビルド」。

アイコンが赤いときは、アイコンにマウスを乗せたときに出る文も書いていただけると助かります。調べるのにログが要るときは、[ログ採取方法](log_collection.md)をご覧ください。

## サポート範囲

### 対応すること

- 公開βとして出している最新の版で起きる不具合の調査
- 使い方の質問への回答
- 既知の問題の更新
- 直すと決めたものの修正（次の版で入れます）

### 対応しないこと

これらは**できないこと**であって、頂いた報告を軽く見るという意味ではありません。

- **古い版のサポート。** 最新の版でも起きるか確かめてからお知らせください。
- **Windows 以外の OS。** スマホ版（Android）は、出したときにここを改めます。
- **既知の問題に「仕様として、そうしていること」として書いてあること。** そうする理由があって選んでいます。ただし、ご意見はうかがいます。
- **曲のファイルの入手、変換、タグの編集の手伝い。** HamonPlayer は、持っている曲のファイルを流すだけです。
- **音楽の配信サービスとの連携。** HamonPlayer は、曲のフォルダにある曲のファイルだけを流します。
- **電話や対面での対応。**

### お約束できないこと

**公開βは、個人が余暇に作って無償で配っているものです。**

- **返信の速さをお約束できません。** 数日から数週間かかることがあります。どちらの窓口でも同じです。
- **すべての報告に対応するとはお約束できません。** 直さないと決めることがあります。その場合は理由をお返しします。
- **公開を続けることをお約束できません。** 配布をやめることがあります。そのときは配布元でお知らせします。
- **公開βの間、予告なく挙動が変わることがあります。** 大きく変わるときは[変更履歴](CHANGELOG.md)に書きます。

詳しくは[利用条件](terms.md)をご覧ください。
