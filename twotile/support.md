TwoTile 1.0.2（公開β）時点の内容です。

## 問い合わせ先

窓口は **<https://github.com/poola-vii/support>** の 1 つだけです。メールでは受け付けていません。

| 用件 | 送り方 |
|:---|:---|
| 不具合の報告、使い方の質問、要望 | 上のリポジトリの **Issues** から、用意したフォームを選んで投稿してください |
| 脆弱性の報告 | 上のリポジトリの **Security** タブから **Private Vulnerability Reporting** で送ってください。**公開の Issue には書かないでください** |
| Microsoft Store のレビューに書いた内容 | 気づいたら公開で返信し、この窓口へご案内します。Store のレビューでは個別のやり取りができないためです |

**投稿には GitHub のアカウントが要ります。** 無料で作れます。

### 書かないでいただきたいこと

公開の Issue は誰でも読めます。次を書かないでください。

- **未加工のログ** — [ログ採取方法](log_collection.md)のとおり、中身を読んで秘匿化してから貼ってください
- **個人情報** — 氏名、住所、電話番号、メールアドレス、勤務先など
- **認証情報** — パスワード、トークン、APIキーなど
- **まだ公表されていない脆弱性の情報** — Private Vulnerability Reporting をお使いください

投稿された内容がこれに当たると判断したときは、こちらで編集または削除することがあります。

### 知らせていただきたいこと

[ログ採取方法](log_collection.md) §3 を見てください。**何をしたら何が起きたか・TwoTile の版・Windows の版**の 3 つがあると、たいていのことは調べられます。

## サポート範囲

### 対応すること

- 公開βとして出している最新の版で起きる不具合の調査
- 使い方の質問への回答
- [既知の制限](known_issues.md)の更新
- 直すと決めたものの修正（次の版で入れます）

### 対応しないこと

これらは**できないこと**であって、頂いた報告を軽く見るという意味ではありません。

- **古い版のサポート。** 最新の版でも起きるか確かめてからお知らせください。
- **対応しないと決めている環境。** ARM の PC、32 ビットの Windows、Windows 以外の OS。
- **[既知の制限](known_issues.md)に「仕様として、そうしていること」として書いてあること。** そうする理由があって選んでいます。ただし、ご意見はうかがいます。
- **個別の環境に合わせた作り込み。** 特定のアプリのためだけの機能は入れません。
- **他のソフトとの組み合わせで起きる問題の切り分け。** 他のウィンドウ管理ソフトと一緒に動かすと、互いにウィンドウを奪い合います。
- **電話や対面での対応。**

### お約束できないこと

**公開βは、個人が余暇に作って無償で配っているものです。**

- **返信の速さをお約束できません。** 数日から数週間かかることがあります。
- **すべての報告に対応するとはお約束できません。** 直さないと決めることがあります。その場合は理由をお返しします。
- **公開を続けることをお約束できません。** 配布をやめることがあります。そのときは配布元でお知らせします。
- **公開βの間、予告なく挙動が変わることがあります。** 大きく変わるときは[変更履歴](CHANGELOG.md)に書きます。

詳しくは[利用条件](terms.md)をご覧ください。
