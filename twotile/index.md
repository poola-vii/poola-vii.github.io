**ウィンドウをどこに置くか、考えなくて済むようにする Windows 常駐ソフトです。**

新しいウィンドウが開くたびに、どこへ置くか考えています。少しずらす、重なりを直す。一日に何十回もやっていて、そのたびに手が止まります。TwoTile は、その判断をやめるために作りました。タスクトレイに常駐し、開くたび・閉じるたびに、置いた場所の近くで自動的に整えます。**操作を覚える必要はありません。**

もとは作者が自分用に書いたもので、**20年以上、仕事でもプライベートでも毎日使ってきました。** 配置し直す煩わしさが消えて快適だったので、人に渡せる形に作り直しました。

## 見えていればいいのは、2つだけ

普段ほんとうに見えている必要があるのは、いちばん上の2つ——**参照用と操作用**——ではないか。その仮説から作りました。名前の TwoTile はここから来ています。この2枚を画面いっぱいに並べます。

もちろん例外はあります。手順書を見ながら作業するときは 3x1 や 2x2 にできます。決まった幅がないと使いものにならないウィンドウには、幅を指定できます。触ってほしくないウィンドウは除外できます。**例外を設定できるようにしたうえで、普段は何も考えなくていい**、という作りです。

## できること

- **設定なしで使えます** — 分割数は画面の広さから自動で決まります。入れて放っておけば整います。
- **置いた場所を尊重します** — ウィンドウは「今いる場所にいちばん近い」枠へ向かいます。勝手に端へ寄せたりしません。
- **並べ方を変えられます** — 3x1、2x2 など、そのときの作業に合わせて選べます。
- **例外を決められます** — 並べたくないウィンドウは除外、決まった幅が要るウィンドウには幅を指定。
- **いつでも止められます** — タスクトレイから一時停止できます。

使い方の詳細は、アプリのタスクトレイメニューの「ヘルプ」にあります。利用条件と第三者ライセンスの全文も、ヘルプで読めます。

## 何をしないか

「気づくと整っている」を成り立たせるには、存在を主張しないことが要ります。

- **前面に出ません。** 並べ直すために自分が手前に来ることはありません
- **フォーカスを奪いません。** 入力中に持っていかれることはありません
- **並べ直すときに、音も通知も出しません**
- **通信しません。** 利用者の情報を集めません。設定は PC の中のファイルにだけ保存します

> **これは無料の公開βです。** 安定版ではありません。動かない場面や、確かめていない環境があります。[既知の制限](known_issues.md)を読んでからお使いください。

## 動作条件

| | |
|---|---|
| OS | Windows 11（64 ビット）。Windows 10 は**未検証**です |
| CPU | x64。ARM と 32 ビットには対応しません |
| .NET | **不要**です。実行に必要なものは同梱しています |
| ヘルプの表示 | WebView2 ランタイム。Windows 11 には最初から入っています |
| ディスプレイ | 1920x1080 以上を想定しています。並べるのはメインのディスプレイにあるウィンドウだけです |

## 入手する

### Microsoft Store 版（おすすめ）

<https://apps.microsoft.com/detail/9NFM07C9TNPS>

Store から入れてください。更新は Store が知らせます。**Smart App Control がオンの PC では、Store 版をお使いください。**

### ポータブル版

**Store が使えない PC 向けです。** インストールは要りません。`TwoTile.exe` を好きな場所に置いて実行してください。

- 入手先: <https://github.com/poola-vii/TwoTile-releases/releases>
- ほかの人に紹介するときは、ファイルを渡すのではなく、このページを教えてください。ほかの人から受け取ったファイルは、下の「入手したファイルを確かめる」で本物かどうかを確かめてから使ってください（配り方の決まりは[利用条件](terms.md) §4）。

**ポータブル版には署名を付けていません。** そのため次のことが起きます。

- **初回起動時に「WindowsによってPCが保護されました」という警告が出ます。** 「詳細情報」を押して「実行」を選ぶと起動します。
- Smart App Control がオンの PC では起動できません。Store 版をお使いください。

#### 入手したファイルを確かめる

ダウンロードしたら、配布元のものと同じか確かめてください。PowerShell で次を実行し、表示された値がこのページに載せた値と同じであることを見ます。

```pwsh
Get-FileHash .\TwoTile.exe -Algorithm SHA256
```

| 版 | ファイル | SHA-256 |
|:---|:---|:---|
| 1.0.2 | `TwoTile.exe` | `53CA0DF4CDF9EDCAE19F4E5CE5098CA2677FE7E80749F5873B881E9D9347ED8F` |
| 1.0.1 | `TwoTile.exe` | `44C461CD82A0A6989F2702DD915119C3A23EF5EBC775EBC3AF13838228CD4F1D` |

値が違うときは使わないでください。

## 最初に使うとき

1. `TwoTile.exe` を実行します（Store 版はスタートメニューから起動します）。
2. タスクトレイに 2 色のアイコンが出ます。ウィンドウがあれば、数秒のうちに並びます。
3. アイコンを右クリックするとメニューが開きます。
4. 止めたいときは「自動整列 有効」のチェックを外します。終わるときは「終了」を選びます。

**最初は自動で起動しません。** Windows のサインイン時に起動させたいときは、メニューの「OS起動時に自動実行」を使います（Store 版は Windows の設定のスタートアップで切り替えます）。

設定は `%APPDATA%\TwoTile\config.json` に保存されます。アプリを消しても残るので、要らなければ手で削除してください。
