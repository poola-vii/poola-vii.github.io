うまく動かないときに、調べるための情報を取り出す手順です。[問い合わせ](support.md)のときに添えてください。

**TwoTile はログをファイルに書き出しません。** 記録はアプリの中にだけ置いていて、終了すると消えます。**アプリを終了する前に**取り出してください。

**取り出した文面は、送る前に必ずご自身で読んでください。** ウィンドウのタイトルが含まれます。渡したくない情報があれば、消してから送ってください。

## 1. 動いているときの記録を取り出す

1. タスクトレイの TwoTile のアイコンを右クリックし、**「デバッグ表示」**を選びます。
2. 「TwoTile - デバッグログ」という窓が開きます。直近の配置の記録と、警告・エラーが新しい順に最大 50 件出ます。
3. 左下の**「ログをコピー」**を押します。クリップボードに入ります。
   - 特定の行だけ渡したいときは、その行をクリックして選んでからコピーします。複数の行を選ぶときは Ctrl キーを押しながらクリックします。
   - キーボードでも操作できます。**Ctrl+A** で全選択、**Ctrl+C** でコピーです。
4. 問い合わせの入力欄に貼り付けます。
5. **貼り付けた内容を読んでください。** ウィンドウのタイトルに、ファイル名やページのタイトルなど、渡したくないものが入っていないか確かめます。あれば消すか、`***` などに置き換えてください。

### 取り出せる文面

先頭に、調べるのに要る TwoTile の版と Windows の版が入ります。

```
TwoTile v1.0.1 のデバッグ表示
Windows: Microsoft Windows NT 10.0.26200.0
取り出した日時: 2026-09-18 08:02:44

[2026-09-18 08:02:20] [Adjustment] [調整] "ウィンドウのタイトル" (クラス名) (980,496,600,400) -> (0,0,1280,1392)
[2026-09-18 08:02:16] [Adjustment] [調整] "別のウィンドウ" (クラス名) (44,52,1129,635) -> (0,0,1280,1392)

※ 貼り付ける前に、ウィンドウのタイトルなど渡したくない情報が含まれていないか確かめてください。
```

`[調整]` の行は「このウィンドウを、この位置からこの位置へ動かした」という記録です。括弧の 4 つの数字は、左端・上端・幅・高さです。

### 記録が残っていないとき

- TwoTile を起動し直すと、それまでの記録は消えます。**起こったことを再現してから**取り出してください。
- 配置が起きていなければ記録は空です。その場合は「何も起きなかった」ことがそのまま手がかりになります。空のままコピーして送ってください。

## 2. 起動できないときの情報

起動に失敗すると、**「TwoTile 起動エラー」**という窓が出ます。

1. 窓が出ている状態で **Ctrl+C** を押します。窓の文面がまるごとクリップボードに入ります（Windows の標準の動きです）。
2. 問い合わせの入力欄に貼り付けます。
3. 貼り付けた内容を読み、渡したくない情報（ファイルのパスにユーザー名が入っていることがあります）があれば消してください。

窓が出ずに、何も起こらないまま終わるときは、その旨をお知らせください。

## 3. あわせて知らせていただきたいこと

ログだけでは分からないことが多いので、次を書き添えてください。**このうち上の 3 つがあると、たいていのことは調べられます。**

- **何をしたら、何が起きたか。** できれば手順を順番に。
- **TwoTile の版。** タスクトレイメニューのいちばん上に出ます（例: `TwoTile v1.0.1`）。Store 版かポータブル版かも。
- **Windows の版。** 「設定 > システム > バージョン情報」の「エディション」「バージョン」「OS ビルド」。
- 画面の構成。ディスプレイの数と、それぞれの解像度と表示倍率（「設定 > システム > ディスプレイ」）。
- 対象のアプリの名前。どのウィンドウでうまくいかないか。
- TwoTile の設定。グリッド設定の内容や、除外ルールの有無。

`%APPDATA%\TwoTile\config.json` を添えていただく必要は**ありません**。除外ルールにウィンドウのタイトルが入っているためです。必要になったときはこちらからお願いします。
